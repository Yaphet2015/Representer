How to capture the PDF shortcut miss

  1. Confirm this TEST-ONLY build is the loaded unpacked folder and that toggle-overlay is assigned (Ctrl+E / ⌘E) to this extension.
  2. Click Clear log on this page.
  3. Open the controlled HTTP(S) PDF. Click the Representer toolbar button once (panel should open). Leave this log empty of previous noise.
  4. Close the side panel. Click the native PDF canvas so it has focus. Press Ctrl+E / ⌘E once. Do not click the toolbar again.
  5. Return here (or let it auto-refresh). Screenshot this table, or copy the JSON.

How to read a row: no event after the keypress means Chrome did not deliver onCommand to the worker (the PDF viewer may have eaten the key). no-tab / no-usable-url means the command arrived but activate() returned before sidePanel.open. open-called then open-failed means Chrome rejected the open (error text is an API message only). A toolbar row should appear as action / open-called / open-ok for comparison.
